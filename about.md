**Node:** 578494
**Callsign:** KJ7T
**Type:** Radio-free node with AllStar 3 and DVSwitch Server

Node 578494 runs on an old Evolve III Maestro E-Book laptop — originally a budget mini-laptop, now stripped down to a headless Debian 13 install and repurposed as a full AllStarLink 3 node. Alongside standard AllStar linking, it runs DVSwitch Server (Analog_Bridge, MMDVM_Bridge, and YSFGateway) with a hardware AMBE dongle, which lets it bridge into DMR via BrandMeister and Yaesu System Fusion (YSF) reflectors — one small, low-power box sitting on three different digital voice ecosystems at once. It's a working demonstration that decent digital-voice bridging doesn't require expensive or purpose-built hardware, just a Linux box with enough headroom to run a few lightweight daemons.
